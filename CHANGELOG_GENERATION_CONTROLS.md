# Changelog: Generation Controls and Customization

## Summary

Added comprehensive control over fairy tale generation with new CLI parameters for setting descriptions, character names, episode/moment limits, and character count limits.

## User Request (Translated from Russian)

> "Add the ability to describe the setting/place of action and give names to characters. The ability to specify not just the number of moves, but maximum number of episodes and moments within one episode. Also add the ability to limit the maximum character count of the fairy tale."

## Changes Made

### 1. Core Library (fableforge-core)

#### `src/generate.rs`
- **Added fields to GenConfig:**
  - `max_episodes: Option<usize>` - Maximum number of episodes to generate
  - `max_moments_per_episode: Option<usize>` - Maximum moments per episode
- **Added builder methods:**
  - `GenConfig::with_max_episodes(max: usize)`
  - `GenConfig::with_max_moments_per_episode(max: usize)`

#### `src/dramatis.rs`
- **Added convenience methods to Persona:**
  - `with_name(name: impl Into<String>)` - Set character name
  - `name() -> Option<&str>` - Get character name
- Character names stored in existing `Persona.attributes` HashMap
- No breaking changes to data structures

**Note:** Setting/place descriptions were already supported via `Tale.initial.setting.place` and `Tale.initial.setting.time`, just not exposed in CLI before.

### 2. LLM Library (fableforge-llm)

#### `src/composer.rs`
- **Added fields to StoryComposer:**
  - `max_characters: Option<usize>` - Maximum character count for generated story
  - `max_episodes: Option<usize>` - Maximum number of episodes to generate
  - `max_moments_per_episode: Option<usize>` - Maximum moments per episode
- **Added builder methods:**
  - `with_max_characters(max: usize)`
  - `with_max_episodes(max: usize)`
  - `with_max_moments_per_episode(max: usize)`
- **Modified compose() method:**
  - Truncates episode list if `max_episodes` is set
  - Truncates moments in each episode if `max_moments_per_episode` is set
  - Stops generation when accumulated text reaches `max_characters`

#### `src/context.rs`
- **Added method to TaleContext:**
  - `total_text_length() -> usize` - Calculate total accumulated text length
  - Used to check character limit during generation

### 3. CLI (cli/fableforge)

#### `src/main.rs`
- **Added CLI arguments to GenerateArgs:**
  - `--place <PLACE>` - Place/setting description
  - `--time <TIME>` - Time period description
  - `--name <NAME>` - Character names (repeatable)
  - `--max-episodes <MAX_EPISODES>` - Maximum number of episodes
  - `--max-moments-per-episode <MAX_MOMENTS>` - Maximum moments per episode
  - `--max-characters <MAX_CHARACTERS>` - Maximum character count

- **Implementation in generate_tale():**
  - Place/time applied to `Tale.initial.setting`
  - Names assigned to `Persona.attributes["name"]` in order
  - Limits passed to GenConfig and StoryComposer

## Examples

### Basic Usage

```bash
# Set place and time
fableforge generate --place "космическая станция" --time "2099 год"

# Give character names
fableforge generate --name "Иван" --name "Василиса"

# Limit episode count
fableforge generate --max-episodes 5

# Limit moments per episode (simpler episodes)
fableforge generate --max-moments-per-episode 2

# Limit total story length
fableforge generate --max-characters 5000
```

### Combined Usage

```bash
# Detective story with full customization
fableforge generate \
  --genre "detective noir" \
  --setting "1940s New York" \
  --place "rainy Manhattan streets" \
  --time "winter 1947" \
  --name "Detective Mike Hammer" \
  --name "Femme Fatale Velma" \
  --max-episodes 6 \
  --max-characters 8000
```

## Technical Details

### Episode Limits Flow
1. Tale structure generated by RandomGen
2. Episodes segmented by Episode::segment(tale)
3. If `max_episodes` set: episodes.truncate(max_episodes)
4. If `max_moments_per_episode` set: each episode.moments.truncate(max_moments)
5. LLM generates text for each episode

### Character Limit Flow
1. After each episode is generated, check `ctx.total_text_length()`
2. If length >= `max_characters`, stop generation
3. Allows natural stopping at episode boundaries
4. Final text may slightly exceed limit due to episode granularity

### Data Flow
```
CLI args
  ↓
GenConfig (structural limits)
  ↓
RandomGen::generate()
  ↓
Tale (with place/time/names)
  ↓
StoryComposer (text generation limits)
  ↓
Episode segmentation + truncation
  ↓
LLM generation (stops when limits hit)
  ↓
GeneratedStory
```

## Migration Guide

### For Library Users

If using fableforge-core programmatically:

```rust
// Old (still works)
let config = GenConfig::new().with_move_count(1..3);

// New (with limits)
let config = GenConfig::new()
    .with_move_count(1..3)
    .with_max_episodes(5)
    .with_max_moments_per_episode(3);
```

### For CLI Users

All existing commands work unchanged. New parameters are opt-in:

```bash
# Old (still works)
fableforge generate --moves 2 --genre fantasy

# New (with customization)
fableforge generate --moves 2 --genre fantasy \
  --place "волшебный лес" --max-characters 5000
```
