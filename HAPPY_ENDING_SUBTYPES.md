# Happy Ending Subtypes (Подтипы Счастливого Конца)

Функция `W` (Happy Ending / Счастливый конец) теперь поддерживает 20 различных вариантов финала для универсального применения в разных жанрах.

## Traditional Fairy Tale Endings (1-6)
Традиционные финалы для классических сказок:

| № | English | Русский |
|---|---------|---------|
| W¹ | Wedding and accession to throne | Свадьба и воцарение |
| W² | Wedding | Свадьба |
| W³ | Accession to throne | Воцарение |
| W⁴ | Promise of marriage | Обещание брака |
| W⁵ | Resumed marriage | Возобновлённый брак |
| W⁶ | Monetary reward | Денежное вознаграждение |

## Universal Endings (7-20)
Универсальные финалы для любого жанра (детектив, научная фантастика, хоррор, драма и т.д.):

| № | English | Русский | Примеры использования |
|---|---------|---------|----------------------|
| W⁷ | Reunion with loved ones | Воссоединение с близкими | Драма, семейное кино |
| W⁸ | Triumph and recognition | Триумф и признание | Спортивная драма, биография |
| W⁹ | Redemption | Искупление | Криминал, драма |
| W¹⁰ | Reconciliation | Примирение | Конфликтная драма |
| W¹¹ | Finding home | Обретение дома | Приключения, coming-of-age |
| W¹² | Justice prevails | Справедливость восторжествовала | Детектив, криминал |
| W¹³ | Great discovery | Великое открытие | Научная фантастика, приключения |
| W¹⁴ | Survival | Выживание | Хоррор, триллер, постапокалипсис |
| W¹⁵ | Hero's sacrifice | Жертва героя | Трагедия, военная драма |
| W¹⁶ | Gaining freedom | Обретение свободы | Политическая драма, исторический |
| W¹⁷ | Inner transformation | Внутреннее преображение | Психологическая драма |
| W¹⁸ | New beginning | Новое начало | Любой жанр (открытый финал) |
| W¹⁹ | Restoration of order | Восстановление порядка | Детектив, фэнтези |
| W²⁰ | Achievement of goal | Достижение цели | Любой целевой квест |

## Примеры применения по жанрам

### Детектив/Криминал
- W¹² — Справедливость восторжествовала (преступник пойман)
- W⁹ — Искупление (раскаявшийся преступник)
- W¹⁹ — Восстановление порядка (разоблачение коррупции)

### Научная фантастика
- W¹³ — Великое открытие (новая технология, контакт с инопланетянами)
- W¹⁴ — Выживание (выжить в космосе, на чужой планете)
- W¹⁸ — Новое начало (новая цивилизация)

### Хоррор/Триллер
- W¹⁴ — Выживание (герой спасается от монстра)
- W¹⁵ — Жертва героя (герой жертвует собой ради других)
- W¹⁹ — Восстановление порядка (зло побеждено)

### Драма
- W⁷ — Воссоединение с близкими (семейная драма)
- W⁹ — Искупление (моральное падение и подъём)
- W¹⁰ — Примирение (конфликт разрешён)
- W¹⁷ — Внутреннее преображение (личностный рост)

### Фэнтези/Приключения
- W¹¹ — Обретение дома (герой нашёл своё место)
- W¹³ — Великое открытие (магический артефакт, тайное знание)
- W²⁰ — Достижение цели (квест завершён)

### Военная/Историческая
- W¹⁵ — Жертва героя (подвиг на войне)
- W¹⁶ — Обретение свободы (освобождение от оккупации)
- W¹⁹ — Восстановление порядка (мир после войны)

## Технические детали

Функция `Wedding` переименована в `HappyEnding` для отражения универсальности финалов:
- Сохранён символ `W` для обратной совместимости с нотацией Проппа
- Название на русском: "Счастливый конец"
- Название на английском: "Happy Ending"
- Фаза: Resolution (Развязка)
- Количество подтипов увеличено с 6 до 20

## Использование в коде

```rust
use fableforge_core::{NarrativeFunction, NarrativeFunctionInstance};

// Традиционная свадьба
let wedding = NarrativeFunctionInstance::with_subtype(
    NarrativeFunction::HappyEnding,
    2  // Wedding
);

// Триумф детектива
let justice = NarrativeFunctionInstance::with_subtype(
    NarrativeFunction::HappyEnding,
    12  // Justice prevails
);

// Выживание в хорроре
let survival = NarrativeFunctionInstance::with_subtype(
    NarrativeFunction::HappyEnding,
    14  // Survival
);
```

## Взаимодействие с LLM

При использовании LLM для генерации текста, описание подтипа передаётся в промпте:
- LLM видит название подтипа (напр., "Справедливость восторжествовала")
- LLM генерирует соответствующий финал истории
- Технический термин "Счастливый конец" не попадает в итоговый текст (согласно обновлённым промптам)
