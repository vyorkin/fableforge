# Telegram Bot Features

## Интерактивная генерация сказок

Telegram-бот FableForge предоставляет удобный интерактивный интерфейс для генерации сказок на основе морфологии Проппа.

## Команды

### `/start`
Приветствие и краткое описание возможностей бота.

### `/generate`
Запускает интерактивный диалог для пошаговой настройки параметров генерации:

#### Шаг 1: Выбор жанра
- **Сказка** — классическая волшебная сказка
- **Фэнтези** — фэнтезийное повествование
- **Нуар** — детективный нуар
- **Хоррор** — хоррор-история
- **Ироничная** — ироничное повествование
- **Пропустить** — без указания жанра

#### Шаг 2: Выбор тона
- **Лирический** — мягкий, поэтичный стиль
- **Мрачный** — тёмный, драматичный тон
- **Ироничный** — ироничный, насмешливый стиль
- **Эпический** — торжественный, величественный тон
- **Пропустить** — без указания тона

#### Шаг 3: Количество ходов
Выберите количество сюжетных арок (moves):
- **1** — короткая одноходовая сказка
- **2** — сказка средней длины
- **3** — длинная многоходовая сказка

#### Шаг 4: Место действия (НОВОЕ)
Опишите место, где происходит действие сказки:
- **Ввести описание** — введите собственное описание (например: "тридевятое царство", "космическая станция", "туманный Лондон XIX века")
- **Пропустить** — место будет сгенерировано LLM автоматически

**Примеры описаний:**
- «тридевятое царство, тридесятое государство»
- «заброшенный космический корабль в глубоком космосе»
- «средневековый замок в горах Шотландии»
- «футуристический мегаполис под куполом»
- «деревня на краю тёмного леса»

#### Шаг 5: Максимальное количество эпизодов (НОВОЕ)
Ограничьте количество эпизодов в сказке:
- **3** — короткая сказка (3 эпизода)
- **5** — средняя сказка (5 эпизодов)
- **8** — длинная сказка (8 эпизодов)
- **Без ограничения** — все эпизоды, сгенерированные из структуры

**Что это даёт:**
- Контроль длины итогового текста
- Экономия API-токенов
- Более быстрая генерация

#### Шаг 6: Максимальное количество моментов на эпизод (НОВОЕ)
Ограничьте количество нарративных функций (моментов) в каждом эпизоде:
- **2** — минималистичные эпизоды (2 момента)
- **3** — стандартные эпизоды (3 момента)
- **5** — развёрнутые эпизоды (5 моментов)
- **Без ограничения** — все моменты из сгенерированной структуры

**Что это даёт:**
- Контроль плотности повествования
- Более лаконичные или, наоборот, детализированные эпизоды
- Управление сложностью сюжета

#### Шаг 7: Seed
- **Случайный** — каждый раз новая структура
- **Ввести число** — для воспроизводимости (тот же seed → та же морфологическая структура)

### `/quick`
Быстрая генерация сказки со случайными параметрами:
- 1 ход
- Без указания жанра и тона
- Без ограничений на эпизоды и моменты
- Случайный seed

### `/structure <количество_ходов>`
Показывает только морфологическую структуру без генерации текста (не требует API-ключа).

**Примеры:**
```
/structure 1
/structure 2
```

**Вывод включает:**
- Исходную ситуацию
- Список персонажей с ролями (сферами действия)
- Ходы с разбивкой по фазам Проппа
- Вложенные ходы (если есть)
- Формулу Проппа в символьной нотации

### `/help`
Справка по всем доступным командам.

## Как это работает

1. **Генерация структуры** — бот создаёт морфологически корректную структуру сказки на основе 32 функций Проппа
2. **Валидация** — проверяет структуру на соответствие каноническим правилам
3. **Применение ограничений** — если заданы лимиты на эпизоды/моменты, они применяются к структуре
4. **Генерация текста** — структура передаётся в LLM (через OpenRouter или Anthropic API) для генерации повествовательного текста

## Настройка

### Переменные окружения

**Для работы LLM-генерации необходим один из API-ключей:**

```bash
# Рекомендуется: OpenRouter (поддержка множества провайдеров)
export OPENROUTER_API_KEY="sk-or-v1-..."

# Или Anthropic API напрямую
export ANTHROPIC_API_KEY="sk-ant-..."
```

**Токен Telegram-бота (обязательно):**
```bash
export TELOXIDE_TOKEN="your-telegram-bot-token"
```

### Запуск

```bash
# Локально
cargo run -p fableforge-tg

# Docker
docker build -f docker/Dockerfile.tg -t fableforge-tg .
docker run --rm -e TELOXIDE_TOKEN -e OPENROUTER_API_KEY fableforge-tg
```

### Деплой на DigitalOcean App Platform

См. основной [README.md](README.md) для инструкций по деплою.

## Формат вывода

Бот отправляет сгенерированную сказку частями:

1. **Персонажи** — имена, эпитеты, внешний вид
2. **Место действия** — описание сеттинга
3. **Эпизоды** — каждый эпизод отдельным сообщением
4. **Формула Проппа** — символьное представление структуры

Каждое сообщение форматируется с использованием HTML-разметки Telegram.

## Технические детали

### Архитектура бота

**Стейт-машина диалога:**
```
Start
  → SelectGenre
  → SelectTone
  → SelectMoves
  → SelectPlace (может перейти в AwaitPlaceText)
  → SelectMaxEpisodes
  → SelectMaxMoments
  → SelectSeed
  → [Генерация]
  → Start
```

**Зависимости:**
- `teloxide` — Telegram Bot API
- `fableforge-llm` — LLM-интеграция
- `fableforge-core` — морфологический движок

### Inline-клавиатуры

Бот использует `InlineKeyboardMarkup` для всех выборов, что обеспечивает удобный UX без необходимости вводить текст вручную (кроме описания места и seed).

### Обработка ошибок

- Ошибки генерации структуры → сообщение "Ошибка генерации структуры"
- Ошибки LLM → сообщение "Ошибка генерации текста"
- Отсутствие API-ключа → предложение использовать `/structure`

## Ограничения

- Максимальная длина сообщения в Telegram: 4096 символов (бот автоматически разбивает длинные тексты)
- In-memory хранилище диалогов (состояние теряется при перезапуске бота)
- Один активный диалог на пользователя
